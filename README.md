# WizFlow

AI-first workflow and approval platform for non-technical managers.

## Documentation

- [Agent handover & phase plan](docs/WIZFLOW_HANDOVER.md)
- [Software Requirements Specification (Draft 1.0)](docs/Wiz%20Flow%20Srs%20Draft.docx)

## Stack (MVP)

- **Web:** React, Vite, Tailwind
- **API:** FastAPI
- **Data:** PostgreSQL, Redis
- **Infra:** Docker, Nginx

Greenfield build — no Form.io server dependency. See handover doc for scope, phases, and architecture.
