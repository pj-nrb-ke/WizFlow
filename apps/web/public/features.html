01

Form Designer & Public Forms

Build forms visually and expose them internally or as tokenized public links.

  • Drag-and-drop designer, ~15 field types
  • Fields: text, date, dropdown, combobox, radio, checkbox
  • Fields: currency, yes/no, label, section, table/grid, button
  • Fields: master-data list, employee selector, calculated field
  • Per-field config: label, key, required, placeholder
  • Role-based field visibility & editability
  • Option sources: static, master-data, org users, external API
  • Calculated fields (e.g. {amount} * 0.15)
  • Save-as-draft & JSON schema export
  • Public forms: revocable tokenized links, optional expiry
  • Guest capture: name + email, honeypot, IP tracking
  • HTML sanitisation on guest input
  • File upload (PDF/JPG/PNG, 10 MB, MIME-checked)
  • Guest portal: accept (auto-account + welcome) / reject w/ reason
  • OCR document extraction to auto-fill fields
02

Workflows

Design, publish and version multi-step approval flows.

  • Create: blank, custom, or AI-generated
  • Drag-to-reorder approval chain
  • Draft → publish pipeline: preview, health-check, simulation
  • Visual workflow preview: rendered form + step flowchart NEW
  • Sequential steps, per-step assignee (role or user list)
  • Per-step SLA hours
  • Conditional routing (skip_to on numeric thresholds)
  • Plain-English "tune" command
  • Template library (Purchase / Leave / Petty Cash) + clone
  • Version history + rollback; workflow clone
  • Excel export
  • Send-form-to-staff + scheduled dispatch (weekly/monthly/once)
  • Submission report with field aggregation
  • Guest-submission inbox
  • Per-workflow UI theme & form layout
03

Requests, Inbox & Approvals

Submit, track, and act on requests through their approval lifecycle.

  • My Requests: status tabs, search, saved filter sets
  • Filters: date / amount / department
  • CSV / Excel export; draft resume & delete
  • SLA / overdue indicators
  • Inbox: split list/detail, rich filters, priority, overdue-only
  • Multi-select bulk approve / reject
  • Comment templates & task claiming
  • Keyboard shortcuts (A/R/↑/↓), auto-advance
  • Detail: approval-chain visualisation + audit timeline
  • Approve / reject / resubmit (returned)
  • CSV + PDF audit export
  • Public approve: single-use email link, no login
04

Reminders & Compliance

Weekday recurring reminders with per-user compliance tracking.

  • Admin/manager rule creation (name, weekdays, send-hour)
  • User / group assignment; edit, toggle, delete
  • Personal occurrence list with acknowledge
  • Compliance report filtered by rule / date / status
  • Metrics: total / done / missed / pending
  • CSV export
05

Recurring Schedules & Obligations

Calendar-based recurrence that opens obligations, checklists and workflow tasks. NEW

  • Recurrence: weekly, monthly (by day-of-month), yearly
  • Interval support (e.g. quarterly); month-end day clamping
  • Timezone-aware, per-schedule send-hour
  • Multiple targets per schedule
  • Target kind: workflow (obligation + emailed submit link)
  • Target kind: acknowledge (mark-done task)
  • Target kind: checklist (spawns next checklist period)
  • Recipients by user and/or user group
  • Per-recipient obligation status (outstanding/submitted/missed)
  • Automatic nag cadence (interval, max count, cutoff)
  • Escalation to supervisor after N reminders
  • Auto-close obligation when recipient submits
  • Run-now / manual fire
06

Checklists

Recurring task checklists with per-task tracking and public completion. NEW

  • Create checklists with ordered tasks
  • Per-task: assignee, priority, weight, attachment-required
  • Categories, start / due dates, timezone
  • Recurring periods (driven by recurring schedules)
  • Carry-over rules (reset / carry)
  • Completion rule: all or threshold %
  • Optional verification step
  • Per-task status & attachments
  • Public task completion via tokenized link (no login)
