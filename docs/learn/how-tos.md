# WizFlow How-Tos

Short, task-focused recipes. For the full picture, see the **User Guide**; to watch, see the **video chapters** in Learning Resources.

---

## Everyday

### How to submit a request
1. **Apps** → open an application → choose a process.
2. Fill the form; attach files or a voice note if needed.
3. **Submit request.** Track it any time under **My requests**.

### How to save a draft and finish later
Your progress auto-saves on the device while you fill a form. Come back to **Apps** or **My requests → Drafts** to continue where you left off.

### How to track a request
**My requests** → click a request → see its status, approval chain and full timeline. Use the tabs (All / In progress / Approved …) to filter.

### How to approve, return, or ask for more info
1. **Inbox** → select a request.
2. **Approve** to pass it to the next step, **Reject/Return** to send it back with a reason, or **Request info** to ask the requester a question without rejecting it.
3. Use the **AI copilot** ("Analyze request") for a summary and a recommendation first, if you like.

### How to delegate your approvals
When you're away, an administrator can set a **delegate** so your approvals route to a colleague. Ask your admin, or check **Settings** if enabled for you.

## Building (managers & admins)

### How to build a form
**Form designer** → drag controls (text, date, amount, dropdown, calculated total, table…) onto the canvas → click a field to set its options, required flag, and who can see or edit it → **Save as draft workflow**.
> 🎬 Chapter 4 — Build a workflow.

### How to build an approval chain
**Custom workflow** → name it → attach a published form → choose **initiators** (who can start it) → drag **approvers** into order (users, groups, or "the originator's manager") → save, then publish.

### How to use a ready-made template
**Templates** → pick one → **Use template** → it's copied into your company as a draft → customise and publish.

### How to create an App with Suites
**Suites** → **Create** (or start from a template like Expense Management) → give it a name, icon and colour → drag your **published** processes in and order them → **Publish**. It appears for your team under **Apps**.
> 🎬 Chapter 5 — Build an App with Suites.

### How to design a process visually (BPMN)
**Process Designer** → start blank, from a template, or "Draft with AI" → drag tasks, approvals and gateways onto the canvas and connect them → set assignees and branch conditions in the panel → **Publish as app** or **Run as native app**.
> 🎬 Chapter 6 — Design a process visually.

### How to publish and version a workflow
Open a draft in **Workflows** → **Simulate** with sample data (a health check runs) → **Publish**. To change a live workflow, create a **new version**, edit the draft, and publish — the old version is archived and kept for audit.

### How to draft a workflow with AI
**AI creator** → describe the process in plain English ("Petty cash up to 5,000 with manager approval, above that add finance") → review the generated form and steps → publish when ready.

## Administration

### How to add users and assign roles
**Admin → Users** → invite by email → set their role (company admin, manager, approver, originator, or a custom role) → optionally set each person's manager (used by "originator's manager" steps).

### How to set up dropdown lists (master data)
**Master data** → choose a category (department, branch, cost centre, vendor, project, expense type…) → add entries. Any form field set to pull from master data will show them.

### How to brand WizFlow for your company
**Integrations / Settings** → upload your logo and set your brand colour. It appears across the web app, public forms, PDFs and emails (with "Powered by WizFlow" kept at the foot).

### How to automate recurring requests
**Recurring Schedules** → create a rule (which workflow, how often, to whom) → it launches on schedule. Use **Reminders** for recurring task nudges and compliance tracking.

### How to push approved data to your accounting system
If **WizGate** is connected (**Integrations**), add a **Post-to-WizGate** step on a workflow. After final approval, WizFlow pushes the approved request into Sage, QuickBooks or Tally automatically.
